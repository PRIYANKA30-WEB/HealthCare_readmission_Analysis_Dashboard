HealthCare_readmission_Analysis_Dashboard
End-to-End healthcare analytics project using  Excel, SQL, Python, and Power BI

**Objective**
To analyze patient readmission patterns, identify high-risk patients, and support hospital decision-making using data analytics.


**Tools Used**
Excel (Data Cleaning)
SQL (Data Analysis)
Python (EDA)
Power BI (Dashboard)


**Key KPIs**
-Total Patients
-Readmission Rate
-Average Length of Stay
-High-Risk Patients
-Revenue Loss

**Key Insights**

1.Elderly patients show higher readmission rates
2.Patients with multiple comorbidities are high risk
3.Certain departments have higher readmission trends


**Business Impact**
-This dashboard helps hospitals reduce readmissions, improve patient care, and optimize operational efficiency.
